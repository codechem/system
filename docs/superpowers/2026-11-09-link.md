# Link component

**Date:** 2026-11-09
**Changes:** uncommitted in the working tree.

## Goal

Build `<cc-link>` from the Figma "Link" component set (file `K7Z7bb2IjqiyDjik5qjEoN`, set `1215:5830`). The linked node `1215:6192` is the documentation frame.

## Requirements

### From Figma

- **Properties:**
  - Size: Extra Large, Large, Medium, Small.
  - State: Enabled, Hovered, Pressed, Disabled.
  - Label text.
  - A hidden leading icon that can be swapped (default `add`).
  - "Show link icon", on by default: a trailing `link` icon in Material Round.
- **Sizes:**

  | Size | Text style | Icon | Gap | Underline | Height |
  |---|---|---|---|---|---|
  | Extra Large | title-l semibold (24/32) | `icon-lg` 32 | `gap-1` | 1.5px | 32 |
  | Large | title-m semibold (20/24) | `icon-md` 24 | `gap-1` | 1.5px | 24 |
  | Medium | label-l semibold (16/24) | `icon-md` 24 | `gap-0-5` | 1.2px | 24 |
  | Small | label-m semibold (14/20) | `icon-sm` 20 | `gap-0-5` | 1px | 20 |

  The leading icon is `icon-sm` (20px) at every size.
- **Colours:** text, underline and icon are `Accent/light`. Pressed turns all three `Accent/main`.
- **Underline:** shown on Hovered and Pressed only. It is drawn as a line centred on the bottom edge of the label's line box.
- **Disabled:** opacity 0.4. Radius `--cc-radius`.
- Figma has no Focused state.

### Behaviour (expected of a link)

- It's a real `<a>`, so it can be followed with the keyboard, opened in a new tab and announced as a link.
- `href`, `target` and `rel` are passed to the inner anchor.
- A disabled link can't be followed or focused, click listeners on it don't fire, and screen readers still announce it as a link.
- Its accessible name is only the label text. The built-in and slotted icons are decorative. An `aria-label` on the host replaces the name.
- `el.focus()` and `el.click()` act on the inner anchor.

## Steps taken

1. **Found the component set.** The linked node was the documentation frame, so I found the `Link` set on the page. Then I read the variants' text styles, bound variables, icon instances and fills, and the underline vector, with `use_figma` (read-only).
2. **Wrote `cc-link.ts`.**
   - **Attributes:** `href`, `target`, `rel`, `size` (`small|medium|large|extra-large`, default `medium` like the other components), `disabled`, and `hide-icon` (Figma's "Show link icon" turned into an off switch, because a boolean HTML attribute can't default to on).
   - **Markup:** renders `<a part="link">` with a `leading` slot, the label slot, and the `link` ligature from the shared `iconStyles`.
   - **Underline:** a `::after` line under the label, `--_underline` thick and centred on the bottom edge. That matches Figma's vector exactly, where `text-decoration` would be placed by font metrics. Because of this, the label is `white-space: nowrap`.
   - **Disabled:** drops `href` and sets `role="link"` and `aria-disabled="true"`. Without `href`, an anchor is neither focusable nor followable, so the role keeps it announced as a link. A host click listener, added first in the constructor, stops clicks from reaching other listeners, like `cc-button`.
   - **Focus, click and naming:** `delegatesFocus` makes `el.focus()` reach the anchor, and `click()` forwards to it, like `cc-checkbox`. `aria-label` is forwarded to the anchor. The `leading` slot sits in an `aria-hidden`, `display: contents` wrapper, so a slotted icon never becomes part of the name.
   - **Focus:** `:focus-visible` uses the same 2px `--cc-border-focus` outline as `cc-button`. The offset is 2px rather than the button's 4px because the link has no padding, so 4px would leave a gap bigger than the gap between the label and its icon. `cc-alert`'s close button uses 2px for the same reason.
   - **Leading icon:** slotted at `icon-sm`. `font-size` is `!important` so Google's `.material-icons-round` 24px doesn't override it (the same reason as `cc-button`).
3. **Stories:** Default, WithLeadingIcon, WithoutIcon, Disabled, and AllVariants (each size, enabled and disabled).
4. **Tests:** `cc-link.test.ts`, 17 tests:
   - defaults;
   - the accessible name is exactly the label;
   - `target` and `rel` passthrough;
   - `hide-icon`;
   - the colour;
   - the underline shows only on hover, at 1.2px;
   - the height and icon size per size;
   - the leading icon is 20px and stays out of the accessible name;
   - `aria-label` forwarding;
   - `focus()` and `click()`;
   - disabled: no `href` plus `aria-disabled`, skipped by Tab, click listeners blocked, and no hover underline.
5. **Registered it** in `src/index.ts`, the `package.json` `exports` (`./link.js`) and the README.

## Left out

- **Focused state:** not in Figma. It uses the button's focus outline.
- **`download`, `hreflang`, `referrerpolicy`:** add them when needed.
- **Wrapping labels:** the underline is drawn for one line only, so labels don't wrap.

| Severity | Finding | Fix |
|---|---|---|
| Important | A slotted leading icon leaked into the name ("add Docs") | The leading slot is wrapped in `aria-hidden` + `display: contents`; a name assertion is added to the test |

| Important | `el.focus()` did nothing (no `delegatesFocus`) | `delegatesFocus: true`; test |

| Minor | Hover tests depended on test order | `afterEach` moves the pointer away |
| Minor | An enabled link without `href` still looks clickable | Left as is; `href` is expected on an enabled link |
| Minor | No tests for the pressed colour or other underline thicknesses | Left as is; checked in Storybook |
