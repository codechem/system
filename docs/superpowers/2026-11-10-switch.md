# Switch (`<cc-switch>`)

## Goal

Build `<cc-switch>`, the Wave C form-associated toggle, from the Figma "Switch" component set. Covers all three variant axes (Size, On, State), the track and thumb geometry, token colours, and the form behaviour shared with `<cc-checkbox>`.

## Requirements

### From Figma

Source: file `K7Z7bb2IjqiyDjik5qjEoN` (CC Design System), node `373:15462` ("Switch button" documentation frame). The component set is `Switch` (`337:6252`), 20 variants.

| Axis | Values | Default in Figma |
|---|---|---|
| Size | Small, Large | Small |
| On | True, False | True |
| State | Enabled, Hovered, Pressed, Focused, Disabled | Enabled |

Geometry:

| Size | Track | Thumb | Inset (off / on) | Focus ring |
|---|---|---|---|---|
| Small | 26 × 16 | 12 × 12 | 2 px | 2 px outside the track |
| Large | 40 × 24 | 18.82 × 19.2 | 2.35 px horizontal, 2.4 px vertical | 2 px outside the track |

Colours (token names from the Figma variables):

| Element | Off | On |
|---|---|---|
| Track, enabled | Surface/surface-highlight | Accent/main |
| Track, hovered or pressed | Surface/surface-2 | Accent/dark |
| Thumb | Text/low-emphasis | Text/high-emphasis |
| Focus ring | Border/focus | Border/focus |

Opacity: Disabled 0.4, Pressed 0.7 (applies to the whole switch).

### From the plan

- Form-associated custom element (Wave C).
- Switch uses `role="switch"` (plan, section 6, Wave C).

### Expected behaviour

- Click, label click, and Space toggle the switch and fire `change` and `input`.
- Disabled: no toggle, host listeners blocked, opacity 0.4, `cursor: not-allowed`.
- Participates in forms: submits its value only when on, is left out when disabled, and resets to its initial `checked` attribute.
- Accessible name comes from the slotted text, or from `aria-label` when there is no text.

## Steps taken

1. Read the Figma set: variant properties, sizes, fills with bound variable names, thumb positions, and the screenshot.
2. Checked every token used exists in `packages/tokens/dist/tokens.css`.
3. Read the house conventions in `cc-button.ts`, `cc-checkbox.ts`, `cc-link.ts` and `shared/icon-styles.ts`.
4. Wrote `packages/components/src/switch/cc-switch.ts`, modelled on `cc-checkbox.ts` for the form plumbing.
   - Inner structure: `label > span.switch > input[role=switch] + span.track > span.thumb`, then the slot.
   - The input covers the track with `opacity: 0`, so clicks and keyboard focus land on the native control.
   - The thumb is a flex child, with `justify-content` switching between `flex-start` (off) and `flex-end` (on).
   - Focus ring: `input:focus-visible + .track` gets `outline: 2px solid var(--cc-border-focus)` and `outline-offset: 2px`.
   - Host click listener, added in the constructor: when disabled it calls `preventDefault()` and `stopImmediatePropagation()`.
5. Wrote `cc-switch.stories.ts`: `Default`, `On`, `Disabled`, `WithoutLabel`, and an `AllVariants` grid (sizes across, states down).
6. Wrote `cc-switch.test.ts` (26 tests after review fixes, Vitest browser mode, Chromium).
7. Registered the component: `src/index.ts`, `package.json` exports (`./switch.js`, before `./custom-elements.json`), and the README (components row and project layout).
8. Verified (see below).

## Left out

- **Hovered, Pressed and Focused in the AllVariants grid.** These are pseudo-states, so the grid shows Enabled and Disabled only. The Figma frame's extra rows are reproduced by the live pseudo-states, not by a story.
- **Transition animation.** Figma shows only static states. Nothing animates, so no `prefers-reduced-motion` handling is needed yet. Add it with the first animation.
- **Label spacing.** The Figma set has no label. The label uses `gap: var(--cc-gap-gap-1)` (8 px), a choice of mine. See designer questions.
- **Code Connect, Changeset, screen reader spot-check, and the React and HTML sandbox checks** from the plan's Definition of Done. These are repo-wide tasks, not part of this component.

## Designer questions

1. **Large thumb geometry.** The Large thumb is 18.82 × 19.2 px, not square, and sits 2.35 px in from the sides and 2.4 px from the top and bottom. Small is a clean 12 × 12 at 2 px. This may be unintended. The component implements it as drawn.
2. **Small track width.** 26 px has no `--cc-unit-*` token (16 px and 24 px do). It is a raw value in the component. A token would remove that exception.
3. **Label spacing.** Figma has no label next to the switch. Confirm the spacing (currently 8 px).
4. **Default state.** Figma's default On is True. The component follows the form convention (`checked`, default off, like `<cc-checkbox>`), not the Figma default. Confirm this matches what the designer expects.
