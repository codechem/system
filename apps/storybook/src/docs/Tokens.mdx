# Tokens

Every colour, size and spacing value in the components comes from a design token. Tokens are CSS custom properties named `--cc-*`, published as [`@codechem/tokens`](https://www.npmjs.com/package/@codechem/tokens) and exported from the Figma Variables. This page reads the built `tokens.css`, so it always shows the current values.

Use them in your own CSS so your app matches the components:

```css
.card {
  background: var(--cc-surface-surface-1);
  color: var(--cc-text-high-emphasis);
  padding: var(--cc-padding-padding-3);
  border-radius: var(--cc-radius);
}
```

Reach for the **semantic** tokens (surface, text, border, accent, …) first. They say what a colour is for, so a theme can change them in one place. The **palette** tokens are the raw colours the semantic ones point at.

To change a token, set it in your own CSS. The components load the tokens inside `@layer cc-tokens`, so a plain rule wins without `!important`:

```css
:root {
  --cc-accent-main: #7753cd;
}
```

## Typography

The typeface is **Kumbh Sans** (`--cc-typeface-typeface`). `@codechem/components` bundles it. If you use the tokens without the components, load Kumbh Sans yourself; see [Getting started](?path=/docs/getting-started--docs).

### Text styles

## Spacing

Padding, gap and margin share one scale built on an 8px unit (`--cc-unit-*`). The step in the name is a multiple of 8px: `--cc-gap-gap-1-5` is 1.5 × 8 = 12px.
