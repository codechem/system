# Product

## Register

brand

## Users

External visitors: prospective clients, candidates and other developers who come to see what CodeChem builds. They skim on a laptop between other things and decide in under a minute whether this is serious, careful work. A smaller group are developers who want to install the library and need to find Getting started, the component list and theming fast.

## Product Purpose

The public frontpage and docs entry for `@codechem/components`, the CodeChem design system shipped as framework-agnostic web components. It shows CodeChem's craft. Success means a visitor leaves thinking "these people sweat the details", and a developer can go from landing to a working install in two clicks.

## Brand Personality

Precise, calm, crafted. Confident without shouting. The components carry the page, and the chrome around them stays quiet. The brand green (CC green, `#008854`) appears with intent, never as a glow.

## Anti-references

- Neon or glass dev-tool landing pages: glows, glassmorphism, gradient text, dark-by-default "hacker" mood.
- Generic SaaS landing pages: logo walls, three identical feature cards, big-number stats, pricing-style blocks.
- The previous version of this page: everything crammed into one crowded bento grid, no navigation.

References that fit: Radix UI and shadcn/ui (calm, components speak for themselves), Park UI (clear docs-first structure), Kokonut UI (confident component previews).

## Design Principles

1. Show, don't tell. Every claim is backed by a live component, not an illustration.
2. One idea per screen. Each page and section has a single job, and the navigation does the rest.
3. Practice what we preach. The site is built only from the published npm package, with its tokens.
4. Quiet chrome, loud craft. Page furniture stays neutral so the components and the green stand out.

## Accessibility & Inclusion

WCAG 2.2 AA: 4.5:1 text contrast, full keyboard navigation, visible focus, semantic landmarks, and a `prefers-reduced-motion` alternative for every animation.
